How to start

1. Start the VM with CD-ROM first and complete GeometricalOS Setup on the IDE disk.

2. Eject the installer disc, then choose Reboot. The installed OS will start from the hard disk.

This page loads the pinned v86 emulator and BIOS files from public CDNs. No network relay is configured for the guest; GeometricalOS itself remains offline.
